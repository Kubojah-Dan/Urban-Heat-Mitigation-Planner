# UrbanCool AI — Frontend

## Overview
React (Vite) dashboard for the UrbanCool AI planner.  
Populated in **Phase 5**. This directory is scaffolded in Phase 0 to satisfy
the repository structure contract.

## Planned Stack
- **React 18** (Vite)
- **React-Leaflet** — choropleth map rendering
- **Lucide-React** — icon set
- **CSS Modules / Vanilla CSS** — styling

## Setup (Phase 5)

```bash
npm install
npm run dev        # development server at http://localhost:5173
npm run build      # production bundle
```
